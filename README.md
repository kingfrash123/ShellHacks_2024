habits and manage custom budget categories

## Features

## Installation

1. Clone the repository:
   ```sh
   git clone https://github.com/kingfrash123/ShellHacks_2024.git
   ```
2. Install dependencies:
   ```sh
   npm install
   ```
3. Run the project:
   ```sh
   npm start
   ```
